# My Inflation Bot

Бот в тг для подсчета личной инфляции по основным категориям расходов, а также сравнением с актуальной инфляцией от ЦБ РФ

## Технологии:
- Python
- Aiogram
- Matplotlib
- Numpy
- BeautifulSoup4
- Requests

## Запуск
```bash
pip install numpy requests aiogram matplotlib beautifulsoup4 
python3 main.py
